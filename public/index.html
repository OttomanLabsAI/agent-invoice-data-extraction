Invoice intake agent

Reads the supplier invoices that land in the accounts mailbox, fills in the details, and hands you a Sage Intacct bill to check and post - or to key in from the entry sheet.

Download the latest build See what it does

What it does, in four steps

  1. Watches the invoices mailbox. New emails with a PDF or image attached are picked up when you click Check inbox now or on a timer - or you drop a file on the page yourself.
  2. Reads each invoice. Claude fills in the supplier, invoice number and dates, every line, the VAT treatment including the domestic reverse charge, CIS and retention, and checks that the sums add up.
  3. Turns it into a Sage bill. The vendor, GL accounts, tax details, project and payment terms are matched from your coding maps. Anything it cannot match becomes a check to fix before approval.
  4. You review and post. Open the invoice, compare the fields with the document and the Key into Sage sheet, approve it, then post it to Intacct as a draft or key it in by hand. A CSV of everything drops into the purchase invoice log.

It runs on the accounts machine, not in the cloud. Once started, it lives at http://localhost:8765 in your browser. API keys, the Gmail token and every invoice stay in the data folder on that machine. This website only hands out the downloads.

The three pages

Get it running

One machine, one browser tab. The first start takes a minute or two while it sets itself up; after that it starts straight away.

  1. Download the latest build above and unzip it somewhere sensible, such as a folder called Invoice agent in Documents.
  2. Have Python 3 on the machine (3.11 or newer). On Windows, install it from python.org and tick Add python.exe to PATH in the installer. Macs and Linux machines usually have it already.
  3. Start it. On Windows, double-click run.bat. On a Mac, open Terminal, type bash (with a space), drag run.sh into the window and press Enter. The window that opens is the app running - leave it open while you work; closing it stops the app.
  4. Open http://localhost:8765 in your browser. The Inbox tells you what still needs connecting.

Set up, on the Settings page

Every key field is masked; the eye button reveals it so you can check a paste. Save with the button at the top or the bottom of the page.

  1. Claude. Paste an API key from the Claude Console. Test key checks it without spending tokens.
  2. Gmail. In Google Cloud Console create a project, enable the Gmail API, create an OAuth client ID of type Desktop app, paste its client ID and secret, save, then click Connect Gmail and sign in as the invoices mailbox. If Google reports redirect_uri_mismatch, create the client as Web application instead and add the redirect URI shown on the Settings page.
  3. Sage coding. Fill the maps from your Intacct lists: vendor names to vendor IDs, GL account per line category, VAT tax details, project codes, payment terms, and the CIS and retention control accounts. Anything unmapped shows up as a check on the invoice, where you can type the ID directly.
  4. Sage Intacct connection (optional). With Web Services credentials an approved invoice can be posted straight in as a draft bill. Without them everything still works: entry sheet, JSON, XML and CSV.

Processed emails are marked read and labelled Invoices/Processed, and that label is always excluded from the next search, so nothing is read twice. Only PDF, PNG, JPG and WEBP attachments are read; images under 20 KB are treated as logos and skipped.
